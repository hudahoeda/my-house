# 7) Best renovation measurement checklist for on-site verification

Before you renovate, measure these on site with a tape or laser meter:

## Structure

* outside wall to outside wall
* wall thickness of every partition
* column sizes
* beam drops if any

## Each room

* clear inside width
* clear inside length
* floor-to-ceiling height
* window width/height/sill height
* door width/height
* door swing direction

## Wet areas

* bathroom drain position
* toilet center position
* slope direction
* water inlet points
* sewer line route

## Exterior

* carport slope
* front setback
* rear yard drainage
* roof overhang
* fence/gate opening width
